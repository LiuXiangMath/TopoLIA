
The PDBbind datasets used in this work can be downloaded from:

[pdb file](https://weilab.math.msu.edu/Downloads/DTDL/all-pdbs.zip)
[pqr file](https://weilab.math.msu.edu/Downloads/DTDL/all-pqrs.zip)



The LBA30 and LBA60 datasets can be downloaded from [https://www.atom3d.ai/](https://www.atom3d.ai/)

The dataset for docking power can be downloaded from [https://weilab.math.msu.edu/AGL-Score](https://weilab.math.msu.edu/AGL-Score)


After downloading, extract the files and place them under:

```bash
./data
```
